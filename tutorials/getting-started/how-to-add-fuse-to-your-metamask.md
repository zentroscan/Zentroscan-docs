# How to add Zentroscan Coin to your Metamask

1. To set up Zentroscan Coin as a new network on Metamask. Click on the network selector at the top of the app and then choose "Custom RPC" from the list:   ![](../../.gitbook/assets/etz1%20%281%29.png)  
2. Then in the "New RPC URL" enter this address: New rpc URL: **`https://rpc.zentroscan.com/`**

{% hint style="success" %}
Optionally you can add the full parameters:

**Additional**: [https://rpc.zentroscan.com/](https://rpc.zentroscan.com/)  
**ChainId**: 0x17DD1  
**Explorer**: [https://Zentroscan.com](https://Zentroscan.com/)  
**Symbol**: Zentroscan Coin
{% endhint %}

![](../../.gitbook/assets/ez2.png)  


{% hint style="danger" %}
**Note: Please make sure you send Zentroscan Coin assets to only other Zentroscan chain wallets and not any exchanges. We won't be able to retrieve the funds in case Zentroscan assets are sent to non Zentroscan Coin chain supported wallets/exchanges.**
{% endhint %}
