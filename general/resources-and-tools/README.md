# Resources & Tools

### DApp Management & Development Tools

The Graph supports Zentroscan Coin data indexing, quierying and display.

Remix IDE: It's easy to deploy on Zentroscan Coin with Remix, simply choose injected web3 and add the Zentroscan Coin custom RPC to your Metamask.

JustSmartContracts: another smart contract deployment tool for EVM chains.

OpenZeppelin Defender: Manage smart contract administration including access controls, upgrades and pausing.
