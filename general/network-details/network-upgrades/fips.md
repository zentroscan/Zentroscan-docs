# FIP's



### What is a FIP?

FIP stands for Zentroscan Coin Improvement Proposal. A FIP is a design document providing information to the Zentroscan Coin community, or describing a new feature for Zentroscan Coin. The FIP should provide motivation and technical specification for the feature.
