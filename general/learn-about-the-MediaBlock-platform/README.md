# Learn about the Zentroscan Coin Platform

Zentroscan Coin is a decentralized payments-focused platform powered underneath by the fast and low-cost Zentroscan Coin blockchain.&#x20;

In this section, you will be able to learn more about:

* the vision and strategy behind the platform and its main components
* how the Zentroscan Coin blockchain works, its native Zentroscan token and its governance and development
* how Zentroscan Coin is connected to other major chains
